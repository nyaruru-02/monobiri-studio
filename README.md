# MONOBILI COMMISSION

イラスト・調声・UST制作のコミッションサイトです。HTML / CSS / JavaScriptだけで動作します。

## ローカルで開く

このリポジトリをダウンロードしてVS Codeで開き、`index.html`をブラウザーで開いてください。Live Serverなどの拡張機能も利用できます。依存パッケージのインストールやビルドは不要です。

## ページ

- ホーム: `index.html#home`
- 規約: `index.html#terms`
- イラスト: `index.html#illustration`
- 調声: `index.html#tuning`
- ust: `index.html#ust`

## 編集箇所

- `index.html`: 各ページの文章・リンク
- `styles.css`, `illustration.css`: 共通デザインとイラストページ
- `app.js`: ページ切り替え・イラストのスライドショー・通常等身/SDの見積もり
- `tuning.css`, `tuning.js`: 調声ページ
- `ust.css`, `ust.js`: ustページ
- `assets/`: 画像

作品画像・調声/USTのスライドは仮サンプルです。pixivとGoogleフォームはURL未設定のため準備中です。公開前に実際の素材・URLへ差し替えてください。

## GitHub Pages

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で公開元を `main` ブランチの `/ (root)` に設定できます。現時点ではGitHub Pagesの公開設定は行っていません。
